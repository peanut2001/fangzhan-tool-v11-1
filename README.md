# 仿站小工具 V11.1

一个用于站点资源采集与仿站辅助的 Windows 工具项目（当前仓库为已编译程序与依赖文件归档）。

## 项目结构

- `仿站小工具.exe`：主程序
- `仿站小工具.exe.config`：程序配置文件
- `*.dll`：运行依赖库
- `Website/`：项目附带资源目录（如有）

## 运行环境

- 操作系统：Windows
- 运行方式：双击 `仿站小工具.exe`
- 依赖要求：请确保仓库中的 `dll` 文件与 `exe` 位于同一目录

## 使用说明

1. 克隆或下载本仓库到本地。
2. 保持目录结构不变。
3. 运行 `仿站小工具.exe`。
4. 按业务需求在程序内完成相关配置与操作。

## 注意事项

- 本仓库当前主要为二进制发布内容，不含完整源码工程。
- 如程序无法启动，请先检查杀毒软件拦截、系统权限和依赖文件是否缺失。
- 建议在测试环境中使用，并自行评估目标网站的使用条款与合规要求。
